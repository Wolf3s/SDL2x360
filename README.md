# SDL2x360
A working in progress port of the SDL2 Port for XBOX 360
using [RXDK-libSDL2x with tracker support](https://github.com/Team-Resurgent/RXDK-SDL2x/tree/tracker_support) as base

# Contact:
[My Discord](Wolf3s#6897)

# Working Libraries:
- SDL2
- SDL2_mixer
- SDL2_net
- SDL2_image
- SDL2_ttf
